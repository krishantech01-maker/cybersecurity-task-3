# Final Mini Project – Cyber Security Risk Assessment

## Business Scenario
Cloud-based E-commerce Platform

## Key Information Assets
1. Customer Personal Identifiable Information (PII) Database
2. Payment Gateway API Integration Keys
3. Production Source Code Repository (GitHub)
4. Cloud Infrastructure Management Console (AWS)
5. Employee Corporate Email Infrastructure

## Summary of Findings
Conducted a non-technical risk assessment using a qualitative 3x3 risk matrix. Identified critical attack vectors including SQL Injection on Database assets and phishing targeting administrators. Implemented a Python automation engine to dynamically calculate threat scores.
